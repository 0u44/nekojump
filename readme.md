## Why `NekoJump`?

Because cats don’t search — they *know* where to go.
Highest shelf, warmest spot, most-used directory… effortless.

`NekoJump` learns your habits and jumps there instantly.

<sub>

AI choosed this name bc my initial name was so good that I had to change so you wont immediately fall in love with me

</sub>

## Why use this over `zoxide` or `autojump`?

Because it’s cuter :3

Also:

* no magic, just a simple script
* uses only standard Unix utilities
* easy to read, tweak, debug, and eat.
* does exactly what you expect — nothing more

<sub>

Small. Transparent. Hackable.
(and yes… edible if you’re brave enough)

</sub>
